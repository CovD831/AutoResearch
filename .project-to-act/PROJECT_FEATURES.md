# 项目功能

> 本文件是功能范围与状态的唯一清单。详细架构说明位于 `docs/AutoResearch_详细计划书.md`，但功能状态只在这里维护。未验证的功能不得标记为已完成。

## 状态定义

- 候选：尚未批准进入范围
- 已规划：已确认但未开始
- 进行中：正在实现或验收
- 已阻塞：等待外部条件
- 已完成：完成条件已满足且有新鲜证据
- 已取消：明确退出范围并保留原因

## 优先级定义

- P0：首个可用闭环和安全边界必需
- P1：v1.0 必需，但可以在首个纵向切片之后实现
- P2：增强能力，只有 P0/P1 有证据后推进
