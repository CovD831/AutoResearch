# 论文项目功能（模板）

> 复制后这是该论文项目范围与状态的唯一清单；模板阶段不得标记研究功能为已完成。

## 状态定义

- 候选：尚未批准进入范围
- 已规划：已确认但未开始
- 进行中：正在实现
- 已阻塞：等待外部条件
- 已完成：完成条件已满足且有证据
- 已取消：明确退出范围并保留原因
