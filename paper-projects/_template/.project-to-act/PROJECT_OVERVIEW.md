## 项目目标

- 将一个经人工确认的 idea 转化为可审计的研究章程、文献证据、创新候选、工作包、真实结果和本地论文稿件。
- 使用 AutoResearch 的五 Agent、证据门禁、结构化交接和状态机，不允许缺证据跨阶段。
- 目标、进度、功能、版本和验收以本 `.project-to-act` 为唯一治理事实源。

## 范围

### 包含

- 原始 idea、范围、假设、检索、阅读、创新、执行、写作、审核与本地交付。
- 项目证据清单、结构化 handoff、状态投影和知识库稳定链接。
- 真实实验/分析的 RunManifest 和结果 lineage。

### 非目标

- 模板本身不代表任何研究已经开始或完成。
- 默认不包含自动投稿、公开发布、删除原始资产或未经许可的全文获取。
- 不保证创新、实验成功或录用。

## 技术路线与关键约束

- LangGraph 线程与 `PROJECT_MANIFEST.yaml` 的 project/thread ID 一一对应。
- Agent 固定为总控、论文搜索、论文读取、写作、审核。
- 所有跨 Agent 交接保存到 `handoffs/`；所有关键 claim 绑定 evidence ID。
- L3/L4 动作必须经过证据检索、审核、Gate 与按需人工 `interrupt`。
- 大文件使用受控 artifact/object 存储；项目文件保存 hash、locator 和稳定引用。

## 数据与安全边界

- 数据分类：待实例化时填写。
- 全文策略：只允许开放获取或用户有权提供的副本。
- 敏感信息：只记录脱敏摘要、证据 ID 和受控位置。
