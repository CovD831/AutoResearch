## 成员填写

### 「抽取失败」的结构化表达

采用 **`findings = []`（空列表）** 表达抽取失败，**不新增字段、不碰 `contracts.py`**。

依据：O16 §8.1 明确把「`findings` 为**空** **或** 显式标记」列为合法验收结果；
空列表是 `list[str]` 类型天然能表达的最诚实状态，不是哨兵字符串、不是空串。
因此绕开了 forbidden_paths 里的 `contracts.py`（§5 约束 2 与 §8.1 的措辞冲突以 §8.1 为准）。

### 失败标志如何传导到 _citations 与 gaps

- `reader_service.read()`：`findings = sentences[:3]`（去掉 `or [...]` 兜底）；
  `EvidenceItem.claim` 在 `findings` 空时改用诚实题录声明（不伪造 finding），
  避免 `findings[0]` 触发 IndexError。
- `writing_service._citations()`：跳过 `findings` 空的卡（不进 Related Work）。
- `writing_service.draft()`：`failed_cards = [card for card in cards if not card.findings]`
  计入 `unresolved_gaps`（决策 3），措辞 = "N 篇文献未能抽取出可用的发现（仅题录）；其内容未纳入 Related Work。"

### 去重三处路径的调用点

| 路径 | 去重键 | 位置 |
|---|---|---|
| `Related Work` | `findings[0]` 文本 | `_citations()` 内 `seen` set |
| `References` | 规范化标题（`casefold` + 去首尾空白）| `draft()` 内 `seen_titles` set |
| `claims` | 沿用既有 `_unique` | 未改（回归护栏）|

### 「规范化标题」的规则

`" ".join(paper.title.split()).casefold()` —— 去首尾/多余空白 + 统一小写。不去标点。

### draft() 写两次文件的组织方式

直接两次调用 `write_project_file`（签名已支持 filename 关键字参数，无需改签名）：
`filename="MANUSCRIPT_DRAFT_v1.md"`（归档）后 `filename="MANUSCRIPT_DRAFT.md"`（最新指针）。
