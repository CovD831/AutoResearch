# AutoResearch 市场调研与定位分析

- 调研日期：2026-09-03
- 调研方法：三路并行调研（端到端 AI 科研系统 / 文献检索与 MCP·Skill 生态 / 写作工具与行业痛点），GitHub star 数与最近提交为当日实测，其余来自公开报道与论文，来源见文末
- 结论供项目决策参考，不构成功能承诺

---

## 1. 一句话结论

"能自动写论文"已经不稀缺（$15/篇、Nature 已登）；**"论文里的每个数字和引用是真的、且可审计"是 2026 年最稀缺的能力**——Google 和 Anthropic 正在以闭源方式占领它，开源世界基本空白。这恰好是 AutoResearch 已经建了一半的东西。项目的问题不是方向错了，而是：优势停留在设计层没有实证、认知层太薄、摊子铺得太开。建议收缩战场，把"证据/门禁/审计"从内部服务升级为对外交付的产品，用可复核的评测证明它。

## 2. 市场全景

### 2.1 端到端 AI 科研系统

| 系统 | 背景 | 能力边界 | 成熟度 | 关键事实 |
|---|---|---|---|---|
| The AI Scientist v1/v2 | Sakana | idea→实验→写作→自动评审→（实验性）投稿 | v1 14.5k stars / v2 7.1k；2026-03 登 Nature | $15/篇；独立评测 12 个实验 5 个（42%）跑挂；57% 稿件有结构性缺陷，4/7 含错误数字；曾出现幻觉引用；agent 曾改自己的代码绕超时 |
| Agent Laboratory | AMD+JHU | 文献综述→实验→报告，Copilot 定位 | 5.8k stars, MIT | 被 2026 bioRxiv 实测点名"生成完全伪造结果的完整手稿" |
| AI co-scientist | Google | 假设生成→（2026-08 起）实验规划、控设备、写论文 | 闭源，进 Gemini Enterprise；2026-05 登 Nature | **可靠性模块把关键结果伪造率从 46% 压到 4%**（数值声明 vs 执行日志交叉核对，30 专家双盲 450 次评审）；对比系统伪造率高达 90% |
| Robin / Kosmos | FutureHouse / Edison Scientific | 生物学文献→假设→方案，湿实验由人类做 | robin 698 stars；Edison 融资 $70M | 2026-05 登 Nature；"真发现"叙事靠人类湿实验 ground truth 支撑 |
| Zochi | Intology | 宣称全自主到发表 | 闭源（仓库只有复现代码，且被清理过） | 1 篇 ACL 2025 主会 + 2 篇 ICLR workshop；图表/格式/rebuttal 全由人工完成 |
| Claude Science | Anthropic（2026-06-30） | 科学家工作台：60+ 数据库、Jupyter/HPC、reviewer agent | 闭源 beta | **核心卖点就是 auditable artifacts + 从假设到投稿的完整审计链** |

**赛道共同弱点（按严重程度）**：

1. **结果伪造与幻觉是系统性问题**。不加约束时伪造率 46%~90%（Google 双盲数据）；8 框架实测无一跑通"文献→代码→执行→验证"全周期，还记录了"多 agent 循环幻觉"：agent 互相假设对方算出了不存在的结果，用虚假共识让伪造显得已验证。
2. **评估缺乏 ground truth**：Elo 是自评，LLM-as-judge 与人类评审一致性存疑。
3. 成果集中在 ML/NLP 内卷区，泛化未证明；工程脆弱（部署需数小时人工调试）。
4. 治理滞后：署名、披露、检测都落后于系统能力。

**稀缺能力（差异化机会）**：证据链与可审计性（只有闭源大厂在做）；独立于自评的外部验证层；累积性研究记忆与失败知识库。

### 2.2 单环节工具（检索 / 综述 / 写作 / 检测）

- **检索综述**：Elicit（$49/月，系统综述+数据提取表格）、Consensus（$30M 融资，与 OpenAI 合作）、SciSpace、Undermind、Paperguide——"Deep Review 人手一个"，$9-49/月价位挤压，红海。
- **写作润色**：Jenni（~$10M ARR）、Paperpal（300 万用户）、Writefull（被 Digital Science 收购）。被 HN 用户贬为"wrapper，活不过大模型升级"。
- **可信方向的产品化程度**：
  - Scite.ai：Smart Citations（supporting/contrasting 分类），12 亿引用陈述，被 2090 万美元收购——做的是**文献计量层**的可信，不是"AI 写的这句话是否忠于原文"；
  - GPTZero Hallucination Check：NeurIPS 2025 审计 4,841 篇录用论文，确认 51-53 篇（约 1%）含幻觉引用——检测公司顺带做的功能；
  - Paperpal AI Footprint：AI 参与度追踪+披露生成——只解决程序合规，不解决内容真伪。
- **出版商侧**：STM Integrity Hub（40 家出版商、月筛 12.5 万篇）、Proofig/Imagetwin（图像伪造检测）——与作者侧工具完全割裂。

### 2.3 MCP / Skill / 插件生态

- **检索类 MCP = 最大红海**：50+ 个 API 封装项目，一年内约半数停更或死亡（scholar-mcp、pubmed-mcp 等已 404）。Ai2 官方 Asta MCP（托管、免费 key、S2 全库+500 词证据片段）下场后，纯封装类无创业价值。
- **阅读层被 Zotero 生态占领**：zotero-mcp 4.9k stars（已集成 Scite 支持/反对计数+撤稿预警）、papersgpt 2.6k。
- **Skill 生态头部**：K-Dense scientific-agent-skills **42k stars、宣称 19 万科学家使用**，163 个 skill+100 数据库，含 Paperclip（1100 万全文文件系统+行级引用）；Stanford Auto-Empirical-Research-Skills 3.7k（社科 8 学科×9 阶段流水线）。但它们本质是 **skill 集合/prompt 模板，没有执行管控、没有审计框架**。
- **流程管控层刚开跑、无头部**：ScienceClaw（890 stars：零幻觉协议"引用必须来自工具结果"+持久记忆+最少 100 次工具调用的深度强制）、DARE（417：900+ markdown skill 四层编排+回溯规则，写作管线还在 roadmap）、meta-pipe（124：publication-grade meta 分析）。全部在 100-900 star 量级，**没有事实标准**。
- **明确空白**：
  1. **没有系统做成"每个 claim → 证据 → 原文精确位置 → 时效/撤稿状态"的可审计链条贯穿检索→筛选→提取→写作全程**（现有全是散点：zotero-mcp 的撤稿预警、Paperclip 的行级引用、ScienceClaw 的来源约束）；
  2. PRISMA 合规的系统综述**执行框架**（slr-prisma 只有模板没有执行管控）；
  3. 结构化数据提取（Elicit 的核心壁垒，开源几乎空白）；
  4. 断点续跑/检查点/多会话一致性；
  5. 多人协作共享证据库（现有全部单人工具）；
  6. 非英文文献（知网仅 893-star 一家）。

### 2.4 政策环境（2025-2026 急剧收紧 = 刚性需求窗口）

- **幻觉引用 = 伦理违规**：NeurIPS 2026 明确列入 Code of Conduct 违规；ICLR 2026：幻觉引用→作者伦理违规，未披露重度 LLM 使用→直接拒稿；ICML 2026 因违规拒稿近 500 篇。
- 引用幻觉量化：GPT-3.5 55% 编造、GPT-4 18%；NeurIPS 录用论文约 1% 含确认幻觉引用；Nature 估计 2025 年数万篇论文被无效引用污染；欺诈性引用激增 6 倍。
- Wiley/Hindawi 撤稿 11,300+ 篇；ICLR 2026 约 21% 评审是纯 AI 生成（Pangram 估计）。
- **付费意愿排序（有支付证据）**：① 引用真实性与核验（Scite 被收购、Consensus 融资、知乎/r/PhD 最密集抱怨）② 不被 AI 检测误伤+投稿合规（Paperpal 付费动因）③ 机构侧规模化质控（STM Hub、Proofig 的 B2B 合约）。

## 3. AutoResearch 现状对照

已建成（0.1.0，~4,200 行 Python + 测试）：五 Agent LangGraph 父图/子图、SQLite checkpoint、interrupt/resume、结构化 Handoff、H/P/X/R 证据等级、L0-L4 fail-closed 门禁、EvidenceBundle（独立性/时效/冲突/撤稿传播）、append-only 审计、分区知识库、proposal-only 自进化、项目文件夹治理。

未建成/薄弱：真实 LLM 认知层（默认 offline，阅读/写作实为确定性模板）、真实全文管线实战、真实论文试点、PostgreSQL/pgvector/Neo4j、任何对外可复核的评测数字。

## 4. 优势与劣势的诚实评估

### 4.1 真实优势（市场验证过的稀缺方向 + 资产在手）

1. **证据/门禁/审计体系是按"市场最稀缺能力"设计的，且比公开竞品更系统**。Google 可靠性模块只做"数值 vs 执行日志交叉核对"；AutoResearch 的设计多了：独立来源去重、撤稿/更正传播（INVALIDATES/SUPERSEDES）、时效策略、冲突证据强制处理、证据分级（摘要级 P1 不能支撑全文 claim）。这与 bioRxiv 记录的"多 agent 循环幻觉"失败模式正面相对。
2. **确定性 fail-closed + LLM 无权覆盖 + 结构化交接**，在开源界没有等价物（AI Scientist/Agent Laboratory 均无 gate；ScienceClaw 只有 prompt 级约束）。
3. **政策对齐的时间窗口**：NeurIPS/ICLR 2026 把幻觉引用定为违规，"写作时逐条验证引用+留下可审计痕迹"从 nice-to-have 变成刚性需求，市面承接方缺位。
4. **状态机+checkpoint+断点续跑**：调研确认这是空白（只有 DARE 部分做了且未完成）。
5. proposal-only 自进化、经验分级沉淀：独特，且 AgentRxiv/微软 AgentRx 的失败轨迹数据说明这个方向有学术兴趣。

### 4.2 不是优势的地方（避免自欺）

1. **"端到端自动写论文"不是优势，是信誉陷阱**：该能力已商品化（$15/篇）；全自动投稿被会议政策敌视；且我们的认知层（真实 LLM 驱动的阅读/写作质量）远弱于 AI Scientist/K-Dense，今天拿出去比会输。
2. **优势没有被证明**：Google 拿得出 46%→4% 的双盲数据，我们只有设计文档和单元测试。没有公开评测，"防伪造"就只是 README 里的形容词。
3. **检索/阅读/综述单环节全部是红海**：官方 Asta MCP、Zotero 生态、Elicit/Consensus 已占位，不要在这些层做正面竞争。
4. **治理开销过重**：五 Agent + 三层账本 + 大量 YAML，贡献者门槛高、维护成本大，对个人用户不友好。这是内部工程纪律，不该原样暴露给用户。

### 4.3 风险

- Google/Anthropic 以闭源产品占位"可信科研"，窗口期有限（估计 12-18 个月内会出现开源模仿者或官方开放）。
- OpenAlex 转 API key 计费、Crossref 限速——引用核验的成本变量。
- 若继续按 P1-P6 全景路线推进，在第一个真实用户出现前就会耗尽资源。

## 5. 方向建议

### 5.1 战略定位：从"另一个 AI Scientist"改为"开源的可信层"

一句话：**别的系统负责聪明，AutoResearch 负责可信。** 把已经最成熟的 evidence/gate/audit/状态机资产对外输出，而不是在认知层和巨头拼模型调用力。

三层市场对应关系：

| 层 | 谁在做 | 我们做不做 |
|---|---|---|
| 认知层（读/写/实验智能） | 巨头模型 + AI Scientist + K-Dense | 借用，不自研护城河 |
| 工具层（检索/管理/Zotero） | 官方 MCP + 红海 | 直接接入，不重复造 |
| **管控层（证据链/门禁/审计/状态）** | 闭源（Google/Anthropic）+ 早期开源（<900 stars） | **主战场，已有 4000 行资产** |

### 5.2 尖刀场景（收缩到一个）

**"可信文献综述/相关工作写作"**：输入研究问题 → 多源检索（接 Asta/OpenAlex）→ 阅读卡 → 综述/related-work 草稿，其中**每一条事实性陈述绑定"已核验存在的来源 + 原文精确 locator + 撤稿/版本状态"，未绑定的一律显式标注 [未验证]**，并输出一份可交付的审计报告。

选择理由：证据可验证性最强（有原文可对）、需求最大（研究生/科研人员高频）、政策风险最低（辅助而非代写）、正好是当前 0.2.0 Literature Pilot 里程碑的收敛版。

### 5.3 产品形态（两个，同根）

1. **Citation/Claim Auditor**（对外引爆点）：独立 MCP server + Claude Code skill。任何写作 agent（Claude、Cursor、AI Scientist）产出稿件后跑一遍：引用存在性核验、句子级 claim-原文忠实度比对、撤稿/时效检查 → 输出逐条审计报告。市场信号：GPTZero 用同款能力做品牌营销；NeurIPS/ICLR 政策制造刚性需求；zotero-mcp 靠"Scite 计数+撤稿预警"单点功能撑起 4.9k stars。
2. **AutoResearch 核**（框架）：现有五 Agent 架构保留，作为"带门禁的可审计科研工作流"参考实现；上面长出 PRISMA 合规系统综述执行框架（筛选日志、纳入/排除留痕、冲突检测）——调研确认的空白 #1 和 #2。

### 5.4 证明优势：先造评测，再造产品

复刻 Google 的叙事模板，做一个公开 benchmark：同一批写作任务，对比 裸 LLM / AI Scientist 产出 / AutoResearch（gate 开） / AutoResearch（gate 关），指标：幻觉引用率、claim-原文一致率、无证据数字数量。目标：拿出"gate 把伪造率从 X% 压到 Y%"的可复核数字。这一步同时解决"优势未证明"短板，也是最好的营销资产（GPTZero 的 NeurIPS 审计就是先例）。

### 5.5 行动顺序建议（对照现有 P1-P5）

1. **P2 Literature Pilot 收敛为尖刀场景**（不扩大范围）：真实 idea + OA 语料 → 带 locator 的阅读卡 → related-work 段落 → 审计报告。
2. 并行做 Citation/Claim Auditor MVP（从 evidence/gate 服务抽取，接 Asta MCP）。
3. 建立上面的评测 benchmark，发布对比数字。
4. 自进化/画像/创新挖掘/Postgres 迁移全部延后——是差异化故事，不是付费点。
5. 试点验收标准加一条：**第三方可以只凭审计报告复核稿件每个事实性陈述**——这就是对外讲的故事原型。
