## ADR-4 Audit Module 外化

- 决策：核验能力以 `audit/` 模块 + CLI 子命令 + stdio MCP server 对外输出；内部同时作为 gate 的输入源。
- 备选：仅内部使用（放弃市场尖刀）/独立仓库拆分（过早，制造发布负担）。折中：同仓模块、独立入口，S4 后视采用情况再拆仓。
- 后果：新增对外契约面（MCP 工具 schema）需要版本承诺；fail-closed 语义成为对外 SLA（`unknown` 不是错误）。
