> **P0 的对照实验路线已放弃。** 本文档说明处置与留存资产。

## 1. 为什么放弃

**owner 原话（2026-09-15）**：
> 「质量提升**需要一个外部的标准去评判**，要不然无法判断是否提升了质量。」

**原设计 §15 的阶梯里没有"证明经验有用"这一步。** 它靠的是工程机制：

> 「每次晋级或降级都必须有**回归集、证据 ID、审核结论、版本和回滚点**」
> 「模型只能提交 diff 提案，不能直接生效」

**即：经验是否生效，由「沙箱复现 + 回归集 + 人工审核 + 灰度 + 回滚」决定，不由一次对照实验的平均分决定。**

**我用"跑对照实验证明效用"替代了原设计的这套机制** —— 那是研究方法，不是工程机制。而在外部标准不存在时，自造指标测效用**本质上是无判据的**。

### 四次错配（实测）

| 次 | 错配 | 证据 |
|---|---|---|
| 1 | agent 完全不调 LLM | 四条件指标完全相同 |
| 2 | 主指标 `hallucination_ratio` 与"草稿质量"无关 | 实测条件间均为 1.0 |
| 3 | 自造机械指标受跑间噪声支配 | `temperature=0` 实测 **5/5 输出不同**，长度波动 ±13% |
| 4 | **任务本身没有改进空间** | prompt 已把语料参考草稿整个喂给模型；"结构完整度"在拿标题存在性评格式 |

叠加 GP-11 方法学结论：**24 case 严重欠功效**（检出 2–5pp 需 200–400 样本/组）。

### 修掉的 4 个真实缺陷

1. **agent 不调 LLM**（GP-9 实现）→ 产出与经验无关，四条件必然相同
2. **`temperature=0` 不可复现** → 推翻了我写在注释里的断言
3. **`F821 PLACEHOLDER_LINE` 未定义** + **`_BaseLiveDraftAgent` 没继承既有基类** → 都是"没复用既有原语"
4. **placeholder 长度不匹配**（0.59 → 1.098）→ 混淆变量剩大半

## 4. 替代机制（原设计 §15）

| 原设计机制 | 回答什么问题 | 为什么比对照实验好 |
|---|---|---|
| **沙箱复现** | 该经验针对的失败，在受控重放中是否**不再发生** | 判据明确、可复现、**不需要外部质量标准** |
| **回归集** | 该经验的引入是否**破坏了别的场景**（防退化） | 二值/可判定，低方差 |
| **灰度 + 回滚** | 真实环境下的退化能否被**及时发现并撤销** | 把"效用"交给真实反馈 |

**GP-10 的实证支持**：Experience-Following（`arXiv 2505.16067`）证明**无过滤的经验注入会自降级**，只有「选择性添加 + 删除」有正收益 → **回归集就是那个"过滤"的工程实现**。
