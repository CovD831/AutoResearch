## 1. 为什么需要它

**触发问题**：老板问「并行分支不是要做总体的 L1/L2 吗？为什么 P2 没被包含进去？」

**核实结果**：确实漏了。此前的 L1/L2 是按单个 program 出的：

| Program | 覆盖 | 漏掉的 |
|---|---|---|
| R-004 | S1–S4、I0–I4（信任层） | M08 / M12 / M13 / M15 / M17 |
| R-006 | P1–P7（知识/经验） | 但被当成"M11 的实现方案"交付，**M12 部分（P2/P3/P6/P7）没有单独的任务包** |

→ **P2（成熟度阶梯，属 M12）从未被任何 L1/L2 覆盖**，这就是漏洞。
