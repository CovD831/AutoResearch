ELI5 · 超直观版

AutoResearch 是一条“不会乱说话”的科研流水线

你给它一个研究想法，它会像一个小研究团队一样：先定题，再找论文，读论文，想创新，安排实验，写草稿，最后审核。每一步都要带证据；证据不够，红灯就会亮，流程停下来。

1. 一次研究是怎么走的？

💡 想法把 idea 说清楚
🔎 找论文只认真实记录
📖 读论文带定位做笔记
🧪 做计划创新与实验工作包
✍️ 写与审证据够才可放行

2. 五个 Agent，各司其职

🧭

总控 Agent

像项目经理：拆解问题、生成研究章程和工作包，但不能自己宣布“有创新”。

🔍

论文搜索 Agent

像图书管理员：去重、整理题录；找不到论文时不会凭空编造。

📚

论文读取 Agent

像陪读老师：根据全文或摘要做 ReadingCard，并标出引用位置。

📝

写作 Agent

像写作助手：把已放行的证据写进草稿；缺实验就明确写“这里缺证据”。

🛡️

审核 Agent

像质检员：检查证据、来源和缺口，不能修改证据后再自己批准。

3. “红绿灯”为什么重要？

🟢 绿灯

证据分数、独立来源和工作闭环都够，才能进入下一阶段。

🔴 红灯

没有真实论文、证据失效、来源不足、稿件有未解决缺口，流程会停在 WAITING_EVIDENCE。

最严格的一关：外部发布。
即使稿件证据很强，L4 发布仍必须暂停，等待一位具名的人类审批；拒绝就记为拒绝，不能偷偷绕过。

4. 它把什么东西记在账本里？

每个项目都有自己的文件夹（paper-projects/<project_id>），SQLite 保存规范记录和审计事件，另一个 SQLite 保存 LangGraph 的 checkpoint。这样流程中断后可以用同一个 run_id 恢复，而不是从头猜。

5. 你可以怎么运行？

项目要求 Python 3.12+。典型命令是：pip install -e ".[dev]" → autoresearch doctor → autoresearch init-project demo "Evidence-aware agents" → autoresearch run demo --idea "你的研究想法"。默认离线运行；联网和模型需要显式配置。

对应代码入口：src/autoresearch/application.py、src/autoresearch/graph.py、src/autoresearch/agents/。当前仓库版本标注为 0.1.0 foundation：基础纵向切片已成形，但不是生产级多租户系统。
